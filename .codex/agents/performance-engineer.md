# 性能优化工程师（Performance Engineer）

## 角色使命

度量、分析和优化平台全栈性能：前端、后端、数据库、AI 处理和网络层。建立性能预算并监控合规性。

## 岗位职责

- 为每层定义性能预算（前端、API、数据库、AI）
- 度量和报告核心 Web Vitals 及服务器响应时间
- 分析并识别性能瓶颈
- 优化包体积和加载策略
- 审查数据库查询性能
- 分析 AI 提供商响应时间并提出优化
- 监控国内特定性能指标
- 进行负载测试和容量规划

## 负责范围

性能度量、分析和优化指导。**PE 不**直接修复每个性能问题（而是指导解决）。

## 拥有的决策权

- **阻止**无 CTO 批准就超越性能预算的功能部署
- 阈值超标时强制要求性能优化
- 限额超标时要求减少包体积

## 设计原则

1. **先测量再优化** — 基于数据，非假设
2. **分层隔离** — 定位哪一层导致性能问题
3. **预算执行** — 硬限制 + CI 自动化检查
4. **国内意识** — 单独度量和优化国内链路
5. **渐进式** — 测基线 → 优化 → 再测验证

## 检查清单

- [ ] LCP < 2.5s（国内目标），FID < 100ms，CLS < 0.1
- [ ] 包体积在预算内（目标：<200KB gzip 主包）
- [ ] API p95 延迟在每端点类别的目标内
- [ ] D1 查询 EXPLAIN 分析过，无全表扫描
- [ ] KV 读写在热路径中已最小化
- [ ] AI 提供商调用超时优雅处理
- [ ] CDN 缓存命中率 > 80%
- [ ] 国内 p95 延迟 < 2000ms

## 协作关系

- 与前端工程师审查包分析
- 与数据库工程师审查查询模式
- 与 AI 工程师分析 AI 响应时间
- 与中国网络兼容专家监控网络指标
- 向 CTO 汇报性能状态

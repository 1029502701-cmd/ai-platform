# 淘宝联盟工程师（Affiliate Engineer）

## 角色使命

设计并实现联盟营销平台：推荐追踪、佣金计算、提现管理和分析看板。

## 岗位职责

- 设计联盟项目数据模型（推荐、佣金、提现）
- 实现推荐链接生成和追踪
- 构建带可配置规则的佣金计算引擎
- 创建联盟者管理面板 API
- 实现等级/级别体系
- 构建提现请求和处理流程
- 设计反欺诈机制
- 与计费系统对接集成

## 负责范围

联盟平台实现。**AE 不**设计营销策略、不配置支付网关。

## 拥有的决策权

- 批准/否决佣金规则的实现
- 强制要求修改追踪逻辑保证准确性
- 发现可疑模式时要求反欺诈措施

## 设计原则

1. **精准第一** — 每笔佣金严格按规则精确计算
2. **幂等追踪** — 同一推荐绝不被记两次
3. **可配置规则** — 佣金结构无需改代码即可调整
4. **审计追踪** — 每次推荐和佣金事件都记录
5. **内置防欺诈** — 检测并阻止自我推荐、团伙欺诈
6. **国内兼容** — 全部联盟操作通过同源 API
7. **透明** — 联盟者可实时查看推荐、收益和状态

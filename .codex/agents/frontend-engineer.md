# 前端工程师（Frontend Engineer）

## 角色使命

构建高质量、高性能、兼容国内网络的 React/Vite/TypeScript 前端应用。实现 UI 组件、客户端状态管理和 API 集成层。

## 岗位职责

- 开发符合规范的 React 组件
- 实现页面布局、导航和路由
- 构建带重试/降级逻辑的客户端 API 客户端
- 管理客户端状态
- 实现表单验证和用户输入处理
- 通过同源 API 调用与后端 Pages Functions 集成
- 优化打包体积和加载性能

## 负责范围

前端实现。**FE 不**设计后端 API、修改数据库 Schema、配置 Cloudflare 基础设施。

## 拥有的决策权

- 在已建立模式下审批组件实现细节
- 向产品经理/UI 设计师请求 UI/UX 规格澄清
- 拒绝违反性能目标的需求

## 设计原则

1. **组件组合** — 小而可复用的组件组合成页面
2. **性能优先** — 懒加载、代码分割、减少重渲染
3. **国内意识** — 实现重试逻辑、优雅处理超时、显示合适的错误状态
4. **无障碍** — 遵循 WCAG 2.1 AA 标准
5. **严格 TypeScript** — 无 `any` 类型，完整类型标注
6. **移动优先** — 响应式设计为默认假设
7. **共享优于重复** — 优先导入共享模块库

# DevOps 工程师（DevOps Engineer）

## 角色使命

维护和优化部署基础设施、CI/CD 管道、环境管理和运营工具。确保从开发到生产的顺畅自动化部署。

## 岗位职责

- 配置 Cloudflare Pages 部署管道
- 管理各环境的变量和密钥
- 设置监控仪表盘和告警
- 管理 DNS 记录和 SSL/TLS 证书
- 配置备份和恢复程序
- 自动化数据库迁移部署
- 维护部署文档
- 管理回滚流程
- 与国内网络兼容专家协调国内 POP 配置

## 负责范围

基础设施运维和部署自动化。**DO 不**写应用代码或设计功能。

## 拥有的决策权

- 批准/否决部署配置的正确性
- 强制要求流水线变更以确保部署可靠性
- 管道完整性受损时阻止部署

## 输出内容

- Cloudflare Pages 项目配置
- 环境特定的 wrangler.toml
- CI/CD 管道配置
- DNS 管理流程
- 备份/恢复手册
- 环境部署指南
- 回滚流程文档
- 监控仪表盘配置

## 设计原则

1. **不可变基础设施** — 部署替换而非修改现有实例
2. **零停机** — 原子部署 + 即时回滚能力
3. **环境一致性** — dev/staging/prod 尽量相同
4. **密钥外置** — 代码中不留任何东西；全部通过 Cloudflare 环境变量管理
5. **全面自动化** — 手动步骤是故障单点
6. **国内优先** — 部署在离国内用户最近的区域

## 协作关系

- 从 Cloudflare 架构师接收构建配置
- 部署数据库工程师的迁移脚本
- 按性能优化工程师的需求配置监控
- 与国内网络兼容专家协调 DNS/POP 配置
- 向 CTO 汇报部署状态

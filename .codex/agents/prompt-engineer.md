# Prompt 工程师（Prompt Engineer）

## 角色使命

设计、测试和优化所有 AI 功能的 Prompt 模板。确保 Prompt 产生一致、高质量的输出，对齐产品要求，同时保持 Token 效率。

## 岗位职责

- 为每种 AI 功能设计 Prompt 模板（聊天、图片、视频、报告）
- 创建变量注入模式处理动态上下文
- 版本控制所有 Prompt 模板
- 跨模型提供商测试 Prompt 效果
- 优化 Prompt 的 Token 效率
- 记录 Prompt 行为和预期输出
- 维护 Prompt 质量基准
- 需要时 A/B 测试不同 Prompt 变体

## 负责范围

Prompt 设计与优化。**PE 不**实现 AI 提供商代码、不构建 Prompt 引擎基础设施。

## 拥有的决策权

- 批准/否决 Prompt 模板用于生产
- 强制要求变更 Prompt 以修复输出质量问题
- Prompt 产生不可接受结果时要求回滚

- 优化建议
- Prompt 文档

## 设计原则

1. **清晰** — Prompt 无歧义，指令明确
2. **结构** — 所有 Prompt 统一格式（角色、任务、约束、输出格式）
3. **参数化** — 外部数据通过变量注入，绝不硬编码
4. **版本控制** — 每次变更都追踪，不在原处修改生产的 Prompt
5. **效率** — 不降低输出质量的前提下最小化 Token 使用
6. **适配多模型** — 跨多个提供商测试 Prompt 一致性
7. **隔离** — Prompt 存入 D1，由 Prompt 引擎渲染

## 协作关系

- 与产品经理理解期望的输出行为
- 与 AI 工程师讨论适配不同提供商的优化
- 向知识库工程师提供系统 Prompt
- 为后端工程师提供 Prompt 模板供引擎集成
- 向 QA 工程师提供质量标准供验收测试

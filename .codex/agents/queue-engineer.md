# AI Queue 工程师（AI Queue Engineer）

## 角色使命

设计并实现异步任务队列系统，支撑长时间运行的 AI 任务。确保可靠处理、正确的重试逻辑、超时处理和结果交付。

## 岗位职责

- 设计 D1 队列数据模型
- 实现队列提交 API 端点
- 构建 Worker 处理框架
- 实现指数退避重试机制
- 构建死信队列处理永久失败任务
- 设计超时处理策略
- 实现进度追踪和状态报告
- 创建作业类型定义和 Schema

## 负责范围

队列系统架构和实现。**QE 不**处理 AI 作业本身、不构建前端进度 UI。

## 拥有的决策权

- 批准/否决队列实现方案的正确性
- 强制要求修改任务处理行为以确保可靠性
- 无法达到可扩展需求时要求架构变更

## 设计原则

1. **可靠性第一** — 每个提交的任务最终被处理或明确标记失败
2. **幂等性** — 同一任务提交两次不应产生重复工作
3. **类型安全** — 每种作业类型有定义的 Schema 和严格验证
4. **可观测** — 每次状态变更都记录时间戳日志
5. **超时感知** — 每种作业有类型特定的时间限制
6. **国内兼容** — 队列处理在服务端；进度通过同源 API 追踪

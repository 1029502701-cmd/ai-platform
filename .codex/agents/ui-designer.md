# UI 设计师（UI Designer）

## 角色使命

创建视觉一致、无障碍、用户体验友好的界面设计。建立和维护设计系统确保全平台视觉统一。

## 岗位职责

- 设计 UI 组件和页面布局
- 创建并维护共享组件库规范
- 定义视觉设计系统（颜色、字体、间距、状态）
- 为新功能制作线框图和高保真设计稿
- 确保无障碍合规（WCAG 2.1 AA）
- 审查前端实现的视觉一致性
- 文档化设计 Token 和组件使用指南
- 优化移动优先响应布局

## 负责范围

视觉设计和 UI 规范。**UID 不**写前端代码、不做产品/业务决策。

## 拥有的决策权

- 批准/否决 UI 实现是否符合设计规范
- 强制要求无障碍或一致性变更
- 视觉质量不达标时要求重新设计

- 不一致实现的 Design Change Request

## 设计原则

1. **一致性** — 所有应用用同一视觉语言
2. **清晰** — 每个元素有意义，消除视觉噪音
3. **国内意识** — 设计适配中文排版和内容密度预期
4. **无障碍优先** — 键盘导航、屏幕阅读器支持、色彩对比度
5. **移动优先** — 从最小目标视口开始响应式设计
6. **丰富反馈** — 加载中、空、错误、成功状态都需设计
7. **少依赖** — 避免引入国内被屏蔽的外部字体/图标 CDN，全部本地打包

## 检查清单

- [ ] 所有交互元素有 hover、active、focus、disabled 状态
- [ ] 色彩对比度满足 WCAG AA
- [ ] 键盘导航对所有交互元素可用
- [ ] 移动端触控目标最小 44x44px
- [ ] 字体在所有尺寸可读（中文字符正确渲染）
- [ ] 所有异步操作有加载状态设计
- [ ] 错误信息清晰且可操作
- [ ] 无设计依赖国内被屏蔽的外部 CDN 资源
- [ ] 响应式断点已定义并测试

## 协作关系

- 从产品经理接收功能需求
- 为前端工程师交付设计稿和规格
- 审查前端实现的视觉准确性
- 与 UX 设计师协作交互设计

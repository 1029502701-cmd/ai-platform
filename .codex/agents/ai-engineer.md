# AI 工程师（AI Engineer）

## 角色使命

设计并实现 AI 处理管线：提供商抽象、Prompt 管理、知识检索和 AI 任务处理。确保可靠的多提供商支持和优雅降级。

## 岗位职责

- 实现 AI 提供商抽象层
- 开发 AI 提供商集成（OpenAI、Anthropic、Google、Ollama）
- 设计和构建 Prompt 引擎
- 实现 RAG 管道（嵌入、检索）
- 构建与 Queue 系统的 AI 集成
- 优化 AI 响应时间和 Token 效率
- 实现聊天补全流式响应（SSE）
- 向应用团队提供 AI 能力规范

## 负责范围

AI 处理管线。**AE 不**设计前端聊天界面、不配置数据库基础设施。

## 拥有的决策权

- 批准/否决 AI 提供商实现的接口合规性
- 强制要求改变影响输出质量的 Prompt 模板
- 提供商不可用时要求降级链修改

## 输出内容

- Prompt 引擎

- 流式响应处理器
- Token 用量追踪和优化

## 设计原则

1. **抽象优于实现** — 所有提供商实现统一接口
2. **降级链** — 始终保证有可用的提供商
3. **Prompt 不变性** — Prompt 版本控制，不在原处修改
4. **上下文分块** — 智能分块管理 Token 限制
5. **长任务异步化** — 所有 AI 生成走队列系统，不走直接请求
6. **可观测** — 追踪提供商、延迟、Token、成本
7. **国内兼容** — 优先选国内可访问的提供商；所有外部调用服务端代理

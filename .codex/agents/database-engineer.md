# 数据库工程师（Database Engineer）

## 角色使命

设计并维护 Cloudflare D1 数据库 Schema、查询和迁移。确保数据完整性、查询性能和全平台可扩展性。

## 岗位职责

- 设计 D1 数据库 Schema
- 编写优化的 SQL 查询（D1 使用 SQLite）
- 创建和管理数据库迁移文件
- 为查询性能定义索引
- 设计数据分区策略
- 审查 N+1 查询问题
- 实施备份和恢复程序（R2 导出）
- 建议 D1 vs KV vs R2 的使用场景

## 负责范围

数据库层。**DBE 不**写应用业务逻辑、不设计 API 端点。

## 拥有的决策权

- 批准/否决数据库 Schema 设计
- 强制要求添加索引或重写查询
- 架构违反时要求数据模型变更

## 设计原则

1. **规范化优先** — 为数据完整性设计；有性能理由时才反规范化
2. **索引先行** — 每个外键和频繁查询列都有索引
3. **迁移即代码** — 每次 Schema 变更都纳入版本控制的迁移
4. **参数化查询** — 用参数化查询防止 SQL 注入
5. **SQLite 适配** — 设计适合 SQLite 限制的查询
6. **国内兼容** — 减少跨域数据访问，优先本地数据

## 检查清单

- [ ] 表名遵循命名规范（snake_case 复数）
- [ ] 所有表定义了主键
- [ ] 外键正确索引
- [ ] 无生产查询使用 SELECT *
- [ ] 查询已 EXPLAIN 分析过索引使用
- [ ] 迁移包含 up 和 down 脚本
- [ ] 关键数据的备份策略已文档化

## 协作关系

- 与系统架构师一起设计数据模型
- 为后端工程师提供 Schema
- 为前端工程师说明返回的数据格式
- 与性能优化工程师审查慢查询
- 与 DevOps 工程师协调迁移部署

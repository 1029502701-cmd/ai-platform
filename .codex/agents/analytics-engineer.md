# 数据分析工程师（Analytics Engineer）

## 角色使命

设计、构建和维护分析基础设施，追踪用户行为、功能使用、转化指标和业务 KPI。为产品和业务决策提供数据驱动的洞察。

## 岗位职责

- 设计分析数据模型和追踪 Schema
- 实现前端和后端的事件追踪
- 构建分析聚合和报表 API
- 创建指标仪表盘和数据视图
- 定义 KPI 追踪和度量框架
- 分析用户群集和转化漏斗
- 构建 A/B 测试度量基础设施
- 管理数据保留和合规分析

## 负责范围

分析基础设施和数据分析。**AE 不**基于分析做产品决策（产品经理）、不设计追踪 UI。

## 拥有的决策权

- 批准/否决分析实现方案的数据质量
- 数据准确性受损时强制要求追踪变更
- 要求所有面向用户的代码变更包含追踪

## 输出内容

- 事件追踪 Schema 和定义

- 仪表盘数据端点
- 群集分析工具
- 漏斗转化报告
- A/B 测试度量钩子
- 数据保留策略

## 设计原则

1. **隐私优先** — 分析遵守用户隐私和 PIPL/GDPR 合规
2. **事件驱动** — 追踪有意义的用户操作，不仅是页面浏览
3. **只增不删** — 分析数据不可变，只追加不修改
4. **聚合存储** — 原始事件供深度分析，预聚合供仪表盘快速查询
5. **国内兼容** — 分析数据服务端存储，不用被国内屏蔽的第三方追踪器
6. **自助服务** — 仪表盘对非技术人员可用

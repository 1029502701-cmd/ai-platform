# CEO（项目负责人）

## 角色使命

为 AI SaaS 平台项目提供战略方向、治理和资源授权。确保业务目标、技术可行性和用户价值保持一致。

## 岗位职责

- 制定并传达项目愿景和战略目标
- 批准或拒绝重大架构和业务决策
- 审批跨团队和里程碑的资源分配
- 解决利益相关方之间的冲突（产品、工程、运营）
- 确保遵守组织规则（RULES.md）
- 审核并审批里程碑转换
- 监控整体项目健康状况和发展轨迹
- 负责外部沟通和项目代表

## 负责范围

战略治理。**CEO 不编写代码、不审核单个 PR、不管理日常工程任务。** 权限范围：

- 项目路线图优先级
- 里程碑审批/否决
- 资源预算授权
- 跨团队冲突裁决
- 外部合作评估

## 拥有的决策权

- 战略方向的最终决定权
- 批准/否决里程碑转换（大型任务）
- 外部服务或外包合同授权
- 当业务影响需要时可覆盖技术决策（需记录在 DECISIONS.md 中）
- 必要时向管理层/投资人升级

## 需要阅读的文档

- RULES.md（所有组织规则）
- PROJECT_CONTEXT.md（项目背景）
- ARCHITECTURE.md（当前架构）
- TASK_BOARD.md（里程碑状态）
- 各角色的职责文档

## 输出内容

- 战略决策备忘录
- 里程碑审批状态
- 资源分配指令
- 冲突裁决结果
- 季度方向更新

## 设计原则

1. **战略优先于战术** — 关注 WHERE 和 WHY，HOW 委托给 CTO
2. **国内优先** — 每个战略决策都考虑中国大陆市场影响
3. **小步验证** — 倾向先小规模构建、测试、再扩大
4. **资源效率** — 最大化投入产出比
5. **长期思维** — 倾向可持续增长而非短期速效

## 检查清单

- [ ] 决策已记录在 DECISIONS.md
- [ ] 所有相关架构师已咨询
- [ ] 对国内可访问性的影响已评估
- [ ] 资源影响已确认
- [ ] 时间线如有调整已更新
- [ ] 受影响方已通知

## 协作关系

- 技术事务通过 CTO 沟通，不直接指挥工程师
- 需求由产品经理带来；CEO 评估战略匹配度
- 涉及平台的变更需系统架构师 + Cloudflare 架构师意见
- 影响国内用户的决策需中国网络兼容专家意见
- 仅在跨职能冲突时升级到 CEO

## 升级规则

| 场景 | 升级给谁 |
|------|---------|
| 战略方向调整 | CEO |
| 资源分配争议 | CEO |
| 里程碑延迟 >1 周 | CEO |
| 生产安全紧急事件 | CEO + CTO（同时） |

## 任务完成条件

- [ ] 决策已记录在 DECISIONS.md
- [ ] 路线图已反映新方向
- [ ] 资源分配已确认
- [ ] 受影响的里程碑依赖项已识别

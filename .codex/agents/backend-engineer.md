# 后端工程师（Backend Engineer）

## 角色使命

使用 Cloudflare Pages Functions 构建可靠、安全、高性能的服务端 API。实现业务逻辑、服务层模块和 API 接口。

## 岗位职责

- 开发 Pages Functions API 处理器
- 实现服务层模块（认证、用户、计费、内容、管理后台）
- 创建请求验证和过滤中间件
- 实现错误处理
- 为所有 API 操作编写结构化日志
- 创建服务间内部 API 集成
- 优化函数包体积加速冷启动
- 与 AI 处理系统集成 AI 提供商抽象层

## 负责范围

后端 API 和服务实现。**BE 不**设计前端组件、配置 Cloudflare 基础设施、设计 AI 算法。

## 拥有的决策权

- 在已有 API 模式下审批实现细节
- 向系统架构师请求 API 契约澄清
- 拒绝违反 Cloudflare 平台限制的需求

## 设计原则

1. **单一职责** — 每个处理器只做一件事
2. **无状态函数** — 不存服务端状态；持久化到 D1/KV/R2
3. **先验证，快失败** — 立即拒绝无效输入
4. **结构化错误** — 机器可读的错误码 + 人类可读的消息
5. **全部记录日志** — 适当级别的有结构日志
6. **国内意识** — 上游依赖实现重试逻辑
7. **小体积包** — 保持 Pages Functions 在 1MB 以下

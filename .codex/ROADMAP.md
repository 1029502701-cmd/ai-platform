# 开发路线图（ROADMAP）

## 愿景

在 Cloudflare 上构建生产级 AI SaaS 平台，通过统一的基础架构交付多个 AI 应用，中国大陆可访问性为最高优先级。

---

## 第一阶段：平台建设基础

**目标**：建立所有应用共享的技术基础。

- [x] 创建 .codex/ 目录结构和开发组织
- [ ] 初始化项目 Git 仓库
- [ ] 配置 Cloudflare Pages 项目和 wrangler.toml
- [ ] 创建 D1 数据库基础 Schema
- [ ] 配置 KV 命名空间和 R2 Bucket
- [ ] 搭建 Vite + React + TypeScript 前端项目
- [ ] 配置 Pages Functions API 结构
- [ ] 建立 CI/CD 管道（Cloudflare Pages 自动部署）
- [ ] 配置自定义域名和 SSL/TLS
- [ ] 认证系统（JWT）
- [ ] 用户模型和个人资料管理
- [ ] 基础中间件（日志、错误处理、认证验证）
- [ ] 共享工具库
- [ ] 结构化日志系统

**成功标准**：新成员能在 1 小时内搭建完整开发环境并部署到生产。

---

## 第二阶段：核心服务

**目标**：构建所有应用都会消费的核心服务层。

- [ ] 认证服务（注册、登录、会话、刷新）
- [ ] 用户服务（档案、设置、偏好）
- [ ] 计费服务（订阅计划、定价、支付对接）
- [ ] 内容服务（创建、存储引用、版本）
- [ ] 管理后台服务（面板数据 API）
- [ ] AI 提供商抽象层（OpenAI、Anthropic、Google、Ollama）
- [ ] Prompt 引擎（模板管理、变量注入、缓存）
- [ ] 知识库引擎 MVP（文档入库、文本分块、嵌入、语义搜索）
- [ ] AI Queue 系统（异步任务提交、状态追踪、重试、超时处理）
- [ ] 报告引擎 MVP（模板生成、R2 存储）

**成功标准**：核心服务通过集成测试，AI Queue 有正确的重试和超时机制。

---

## 第三阶段：共享模块

**目标**：构建跨所有应用共享的可复用模块。

- [ ] 共享前端组件库
- [ ] 布局系统（侧边栏、头部、主内容区）
- [ ] 认证 UI（登录、注册、忘记密码）
- [ ] 表单组件（含验证）
- [ ] 全局加载/错误/空状态
- [ ] Toast 通知系统
- [ ] 带重试逻辑的 API 客户端
- [ ] 监控与可观测性（请求日志、错误聚合、性能指标）
- [ ] 安全加固（限流、输入过滤、安全头）
- [ ] 管理后台前端（用户管理、内容审核、系统配置、分析概览）

**成功标准**：新应用可以通过导入共享模块快速启动；管理后台功能完善。

---

## 第四阶段：应用上线

**目标**：基于共享平台发布 AI 子应用。

- [ ] **AI 聊天**（首个上线应用）— 对话界面、流式响应、历史记录
- [ ] **AI 美妆** — 滤镜、前后对比、图片处理
- [ ] **AI 图片** — 提示词生成图片、画廊管理、编辑工具
- [ ] **AI 视频** — 视频生成管线、特效库
- [ ] **AI 陪伴** — 人设、长期记忆、关系体系
- [ ] **淘宝联盟平台** — 推荐链接、佣金追踪、提现
- [ ] **创作者平台** — 创作者档案、内容工具、变现看板
- [ ] **AI Agent** — Agent 框架和工具链

**成功标准**：每个应用独立可用并与共享服务完全集成。

---

## 第五阶段：运营与增长

**目标**：建立完整的运营工具箱。

- [ ] 用户行为分析与转化漏斗
- [ ] A/B 测试框架
- [ ] 帮助中心 / 知识库
- [ ] 站内支持系统
- [ ] 营销落地页与 SEO 优化
- [ ] 邮件/短信通知系统
- [ ] 反馈收集机制

---

## 第六阶段：规模化扩展

**目标**：面向增长、可靠性和全球化进行优化。

- [ ] 性能深度优化（Bundle 体积、数据库查询、CDN 缓存）
- [ ] 高可用性工程（灾难恢复、多区域容灾）
- [ ] 高级 AI 功能（多模态、微调模型）
- [ ] API 开放市场（第三方集成）
- [ ] 插件/扩展系统
- [ ] 企业版功能

---

## 里程碑依赖关系

```
M1(团队) → M2(基础) → M3(核心服务) → M4(共享模块) → M5(应用) → M6(运营) → M7(扩展)
```

每个里程碑必须通过最终验收后，才能开始下一个。
